# ADR 0001：維持圖片專用的離線核心

- 狀態：Accepted
- 日期：2026-07-23

## 決策

ImgViewer 維持 Windows、離線、唯讀、圖片專用。核心不加入 PDF、影片、
編輯、媒體庫、遙測、自動更新或外部 plugin API；Portable ZIP 保持一級
發布物。

## 理由

固定邊界能讓少量維護時間集中在圖片解碼安全、窗口穩定、RAM、格式相容
與可重現發布。把不同風險模型的格式或寫入功能加入同一程序，會提高 native
依賴、權限與測試成本。

## 影響

真實需求若超出邊界，先評估獨立程式或明確分離的 process。至少出現三個
獨立且可驗證的擴充需求前，不設計 plugin API。
